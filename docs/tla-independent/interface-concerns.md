# Points where the interface or the supplied files pushed a reading

1. **One scratch P/F bit, staged by the runner.** The runner stages the Enquiry Response F parameter by calling `Processing(c, e, "F := 1")`, the same verb that sets the outgoing frame's F bit. That forces the subroutine parameter and the outgoing P/F bit to be one variable (S6), so the test "F==1 & ..." reads whatever the caller left in P/F.
2. **No distinct names for received and outgoing N(r)/N(s).** Verbs and atoms are opaque strings, and the same spelling "N(r)" serves both roles; the meaning had to decide (S1). A meaning that keeps one N(r) variable would read V(a) := V(r) after Enquiry Response in figc4.5.
3. **The pop is part of the event.** The interface's pop move ("a pop that changes nothing is not a move") and `I_frame_pops_off_queue` imply the head leaves the queue when the event arrives, so `Arrive` does it. With S3's tail push this makes some pops rotate the queue rather than change nothing.
4. **Harness-seeded parameters versus Set Version boxes.** The harness seeds mod, k and n2, but figc4.7b's Set Version expansions assign them (k := 8, k := 32, N2 := 10, modulo). Following the figure overwrites the seeds (S11) and can enlarge the state space (n2 jumps to 10).
5. **Expiry is not a timer state the interface defines.** t1/t3 take "expired", but nothing says when; S2 had to choose.
6. **Received-frame catch-alls.** A frame dispatched as a catch-all carries its fields, so `F := P` and `P_eq_1` work there; a catch-all raised by a primitive carries None, and those verbs then Fail. The interface leaves which catch-alls can be raised by primitives to the harness.
7. **The catalogues carry readings.** `sdl/actions.yaml` comments describe another implementation's dispatcher defaults (for example "defaults: Nr := V(R), PfBit := false" for S frames, and bare verbs consuming pending P/F), and `sdl/predicates.yaml` comments state readings of `vr_lt_ns_lt_vr_plus_k` (open interval) and `vs_eq_nr` (a substitution for a stale read). These are in the permitted files, so they were read; this meaning's choices were made from the spec text and are cited as such, but a comparer should know these comments exist and may have influenced both meanings alike.
8. **Labels only.** Queue entries and the receive buffer hold payload labels, so a retransmitted frame cannot carry its original N(S) unless the meaning invents a richer entry; the meaning kept plain labels (K4 follows from the figure either way).
9. **Fail as a verdict.** The interface says Fail means "the error the reference interpreter would have thrown". This meaning also uses Fail where the figure asks for something that does not exist (S4, an empty queue on pop, Retrieve with nothing stored), which a comparer will see as an error rather than a behaviour.
10. **Saves are ignored.** The Save symbol on DL-DISCONNECT Request (figc4.2, figc4.6) is runner policy and not consumed; this meaning cannot express it.
