# Rows of the current Data Link tables that no calibration scenario fires,
# grouped by cause. TlaCheck compares this list with the never-fired set of a
# full calibration run and fails if a listed row fires or an unfired row is
# not listed, so the accounting cannot rot. docs/tla.md ("The residue")
# explains each group: whether the rows are unreachable in the specification
# itself or only in this harness, and what would make them reachable.
#
# A group line is "group <name>: <spec|harness>: <reason>"; the rows under it
# are table keys, State/transition or Subroutine:path.
