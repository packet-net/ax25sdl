# Rows of the current Data Link tables that no calibration scenario fires,
# each accounted for with a reason. TlaCheck compares this list with the
# never-fired set of a full calibration run and fails if a listed row fires or
# an unfired row is not listed, so the accounting cannot rot. docs/tla.md
# ("Rows not fired") explains each group.
#
# A group line is "group <name>: <status>: <reason>", where the status is one
# of:
#   spec     unreachable in the specification as transcribed (the reason names the issue)
#   harness  not reachable in this harness (the reason says what is missing)
#   not-yet  not yet reached: recorded from bounded attempts, or an existing
#            mechanism could reach it
# The rows under a group line are table keys, State/transition or
# Subroutine:path.
